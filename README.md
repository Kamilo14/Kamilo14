<h2 align="center">Proyectos destacados</h2>

<h3>CatástrofesCL | Plataforma de Gestión de Emergencias</h3>

<p>
  <strong>Proyecto personal · Full Stack Development</strong>
</p>

Plataforma orientada a la gestión y coordinación de emergencias, recursos y voluntarios, desarrollada utilizando una arquitectura distribuida basada en microservicios.

**Arquitectura y responsabilidades técnicas:**

- Diseño y desarrollo de microservicios con Java 21 y Spring Boot, organizados por responsabilidades de negocio.
- Implementación de APIs REST para la comunicación e integración de servicios.
- Implementación de una arquitectura orientada a eventos mediante RabbitMQ, utilizando colas de mensajes para la comunicación asíncrona entre microservicios.
- Integración de PostgreSQL/PostGIS para persistencia y gestión de información geoespacial.
- Implementación de autenticación y control de acceso mediante Firebase Authentication.
- Desarrollo de interfaces web con React y Next.js.
- Containerización de servicios mediante Docker y Docker Compose.
- Implementación de flujos de integración y despliegue con GitHub Actions y servicios de AWS.

**Stack principal:**

`Java 21` `Spring Boot` `RabbitMQ` `PostgreSQL`
`PostGIS` `Firebase` `React` `Next.js` `Docker` `AWS`
